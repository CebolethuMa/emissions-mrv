EmissionsMRV: Blockchain-Based Emissions Monitoring, Reporting and Verification

This is a Solidity smart contract built for my Blockchain Assignment 1. It lets approved facility operators register their facilities and submit emissions record hashes to the Ethereum Sepolia test network so that regulators and auditors can check and verify the records.
